# 🧩 Problem #2243 – Calculate Digit Sum of a String

**Difficulty:** Easy  
**Topics:** `String`, `Simulation`  
**Link:** https://leetcode.com/problems/calculate-digit-sum-of-a-string/

---

## 📝 Problem Summary

Given a numeric string `s` and an integer `k`, repeatedly perform the following operation while `s.length > k`:

1. Divide the string into consecutive groups of size `k`.
2. Calculate the sum of digits in each group.
3. Convert each group sum into a string.
4. Concatenate all group sums to form the new string.

Return the final string when its length becomes less than or equal to `k`.

## 💡 Core Insight

This is a straightforward **Simulation + Group Processing** problem.

We don't need any complicated algorithm or data structure.

The important observation is that we can process groups directly while iterating through the string.

Maintain:
- `sum`: Running sum of the current group.
- `currentRoundAns`: Result of the current round.
- `ans`: String that will be transformed after every round.

Whenever we finish a group, append its sum to the result and reset the running sum.

## 🎯 Pattern Recognition

Look for Simulation + Group Processing when:

- The problem describes repeated transformations.
- Elements must be processed in fixed-size consecutive groups.
- Each group produces a result.
- The output of one round becomes the input of the next round.

Instead of manually extracting substrings, use index-based group boundaries.

## 🚀 Evolution of Thought Process

1. **Understand the operation:** Divide the string into groups of size `k`.
2. **Process each group:** Calculate the sum of its digits.
3. **Merge results:** Append each group's sum to a new string.
4. **Handle incomplete groups:** The last group may contain fewer than `k` characters.
5. **Repeat:** Use the newly generated string for the next round.
6. **Terminate:** Stop when the string length becomes less than or equal to `k`.

### Improvements over my original solution

**1. Remove the digit Map**

Instead of maintaining a mapping for all ten digits:

`numbersMap.get(ans[i])`

Use JavaScript's built-in conversion:

`Number(ans[i])`

This makes the implementation simpler and avoids unnecessary data structure maintenance.

**2. Handle the last group inside the loop**

Original approach:

- Process complete groups inside the loop.
- Handle the remaining group separately after the loop.

Improved approach:

- Process a group when its size reaches `k` OR when we reach the last character.

This removes the separate remainder check.

## 🔍 Detailed Reasoning

### Step 1: Initialize the result

Start with the original string.

```txt
let ans = s;
```

### Step 2: Repeat while necessary

As long as the string length exceeds `k`, another transformation is required.

```txt
while (ans.length > k)
```

### Step 3: Process groups

For every round, initialize:

```txt
let currentRoundAns = '';
let sum = 0;
```

Iterate through every character and add its numeric value to the running sum.

```txt
sum += Number(ans[i]);
```

### Step 4: Detect group boundaries

A group is complete when:

- `(i + 1) % k === 0`
- OR `i === ans.length - 1`

```txt
if ((i + 1) % k === 0 || i === ans.length - 1) {
    currentRoundAns += sum;
    sum = 0;
}
```

Why do we need both conditions?

The first condition handles complete groups.

The second condition handles the final incomplete group.

### Step 5: Start the next round

After processing all groups, replace `ans` with the newly generated string.

```txt
ans = currentRoundAns;
```

Repeat until the stopping condition is satisfied.

## 🧪 Dry Run

|---|---|---:|

`ans.length = 3`

Since `ans.length <= k`, terminate.

## 🧩 Approach 1 — My Solution (Improved)

**Idea:** Repeated Simulation + Group Processing.

### TypeScript Code

```ts
function digitSum(s: string, k: number): string {
    let ans = s;

    while (ans.length > k) {
        let currentRoundAns = '';
        let sum = 0;

        for (let i = 0; i < ans.length; i++) {
            sum += Number(ans[i]);

            // Complete group OR final incomplete group.
            if ((i + 1) % k === 0 || i === ans.length - 1) {
                currentRoundAns += sum;
                sum = 0;
            }
        }

        ans = currentRoundAns;
    }

    return ans;
}
```

## ⚖️ Correctness — Why It Works

1. Every character is processed exactly once per round.
2. The modulo condition ensures that every complete group contains exactly `k` characters.
3. The last-index condition ensures that any remaining characters are also processed.
4. Each group's digit sum is appended to the result in the original group order.
5. The newly constructed string becomes the input for the next round.
6. The loop terminates precisely when the string length is less than or equal to `k`.

Therefore, the algorithm correctly simulates every required transformation and returns the final string.

## ⏱️ Complexity Analysis

Let `n` be the initial string length.

**Time:** O(n log n)

Since `k >= 2`, each round reduces the number of groups to at most approximately half the previous string length.

However, each group sum can contain multiple digits. Therefore, the actual output length is not always exactly `n / k`.

A safe upper bound is O(n log n), and the practical complexity is generally much smaller.

**Space:** O(n)

We construct a new string in every round. The result string requires at most O(n) space.

## 🏆 Key Takeaways

1. Simulation is often the simplest solution when the problem explicitly describes repeated operations.
2. Use index-based grouping instead of unnecessarily extracting substrings.
3. A single condition can handle both complete and incomplete groups.
4. Avoid unnecessary data structures when built-in language features are sufficient.
5. Understand the stopping condition carefully: here, equality with `k` is also a valid stopping point.

## 📚 Pattern Learned

**Repeated Simulation + Fixed-Size Group Processing**

Reusable approach:

1. Initialize a result for the current round.
2. Iterate through the input.
3. Maintain state for the current group.
4. Detect group boundaries.
5. Process and append the group result.
6. Repeat using the transformed output.
