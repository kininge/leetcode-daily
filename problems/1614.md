# 🧩 Problem #1614 – Maximum Nesting Depth of the Parentheses

**Difficulty:** Easy  
**Topics:** `String`, `Stack`       
**Link:** https://leetcode.com/problems/maximum-nesting-depth-of-the-parentheses/

---

## 📝 Problem Summary

Given a valid parentheses string `s`, return the maximum number of parentheses nested inside each other at any point.

For example:

`(1+(2*3)+((8)/4))+1`

The `8` is inside three pairs of parentheses, so the maximum nesting depth is `3`.

---

## 💡 Core Insight

We don't actually need a stack.

We only need to know **how many opening parentheses are currently active**.

- `(` → enter one more nesting level → `depth++`
- `)` → leave one level → `depth--`
- Track the largest `depth` ever reached.

The maximum value of `depth` is the answer.

---

## 🎯 Pattern Recognition

This is a **balance/depth tracking** problem.

Whenever a problem asks about:

- nested parentheses
- currently open brackets
- maximum nesting
- balanced delimiters

think about maintaining a counter.

The counter represents the current nesting level.

Because the input is guaranteed to be a **valid parentheses string**, we don't need to worry about invalid states.

## 🚀 Evolution of Thought Process

### Observation

A pair of parentheses increases the nesting level when we enter it and decreases it when we leave it.

For example:

`((()))`

Process:

`(` → depth `1`  
`(` → depth `2`  
`(` → depth `3`  
`)` → depth `2`  
`)` → depth `1`  
`)` → depth `0`

The largest value reached was `3`.

### Improvement

A stack could technically be used to track the parentheses, but that would store information we don't need.

We don't care **which** parentheses are open.

We only care **how many** are open.

Therefore, a simple counter is sufficient.

---

## 🔍 Detailed Reasoning

Maintain two variables:

- `depth` → current nesting depth
- `maximumDepth` → maximum depth encountered so far

For every character:

1. If it is `(`:
   - increase `depth`
2. If it is `)`:
   - decrease `depth`
3. Update `maximumDepth`.

The important invariant is:

> `depth` equals the number of currently open parentheses.

Since the string is guaranteed to be valid, every closing parenthesis corresponds to a previously opened parenthesis.

## 🧩 Approach 1 — My Solution

Your approach uses exactly the right abstraction: **a counter instead of a stack**.

```ts
function maxDepth(s: string): number {
    let maximumDepth = 0;
    let depth = 0;

    for(let i = 0; i < s.length; i++){
        if(s[i] === "(") depth++;
        else if(s[i] === ")") depth--;

        maximumDepth = Math.max(maximumDepth, depth);
    }

    return maximumDepth;
};
```

### Why it works

`depth` always tells us how deeply nested we currently are.

Whenever we enter a pair of parentheses, the depth increases.

Whenever we leave one, the depth decreases.

By recording the largest depth encountered, we get the maximum nesting depth.

---

## ⚖️ Correctness

The invariant is:

> After processing each character, `depth` equals the number of unmatched opening parentheses currently active.

For `(`, one new parenthesis becomes active, so `depth` increases.

For `)`, one active parenthesis closes, so `depth` decreases.

Therefore, the maximum value reached by `depth` is exactly the maximum number of simultaneously nested parentheses.

---

## ⏱️ Complexity Analysis

**Time:** `O(n)`

Every character is processed exactly once.

**Space:** `O(1)`

Only `depth` and `maximumDepth` are maintained.

No stack or additional data structure is required.

## 🏆 Key Takeaways

1. Don't automatically reach for a stack when you see parentheses.
2. Ask what information the problem actually requires.
3. If we only need the **number of currently open parentheses**, a counter is enough.
4. `depth++` on opening and `depth--` on closing is a reusable balance-tracking pattern.
5. Track the maximum value when the problem asks for maximum nesting.

## 📚 Pattern Learned

### Balance / Depth Counter

General pattern:

```ts
let depth = 0;
let maximumDepth = 0;

for (const char of s) {
    if (char === "(") {
        depth++;
        maximumDepth = Math.max(maximumDepth, depth);
    } else if (char === ")") {
        depth--;
    }
}
```

This pattern is useful for problems involving:

- Parentheses
- Brackets
- Nested expressions
- Balanced delimiters
- Maximum nesting depth
- Current nesting level
