# 🧩 Problem #3622 – Check Divisibility by Digit Sum and Product

**Difficulty:** Easy  
**Topics:** `Math`    
**Link:** https://leetcode.com/problems/check-divisibility-by-digit-sum-and-product/   

---

## 📝 Problem Summary

You are given a positive integer `n`.

Calculate:

1. The **sum of all digits** of `n`.
2. The **product of all digits** of `n`.

Then calculate:

```txt
digit sum + digit product
```

Return `true` if `n` is divisible by this value.

Otherwise, return `false`.

---

### Example

For:

```txt
n = 99
```

Digit sum:

```txt
9 + 9 = 18
```

Digit product:

```txt
9 × 9 = 81
```

Divisor:

```txt
18 + 81 = 99
```

Since:

```txt
99 % 99 === 0
```

the answer is:

```txt
true
```

---

## 💡 Intuition

The problem gives us two values that depend only on the digits of `n`:

```txt
Digit Sum
Digit Product
```

So the natural approach is to extract every digit and maintain two accumulators:

```txt
sum     → starts at 0
product → starts at 1
```

For every digit:

```txt
sum     += digit
product *= digit
```

After processing all digits:

```txt
divisor = sum + product
```

Then simply check:

```txt
n % divisor === 0
```

---

## 🧠 Key Observation

We don't need to convert `n` into a string.

We can extract digits mathematically:

```txt
digit = n % 10
```

and remove the last digit using:

```txt
n = floor(n / 10)
```

For example:

```txt
n = 239
```

```txt
239 % 10 = 9
239 / 10 → 23

23 % 10 = 3
23 / 10 → 2

2 % 10 = 2
2 / 10 → 0
```

So the digits are processed as:

```txt
9 → 3 → 2
```

The order doesn't matter for sum or product.

---

# 🛠 Approach 1 — Digit Extraction and Accumulation

## Idea

1. Keep a copy of `n`.
2. Extract the last digit using `% 10`.
3. Add it to `sum`.
4. Multiply it into `product`.
5. Remove the last digit using integer division by `10`.
6. Repeat until no digits remain.
7. Calculate `sum + product`.
8. Check whether `n` is divisible by it.

---

## Code (TypeScript)

```ts
function checkDivisibility(n: number): boolean {
    let sum = 0;
    let product = 1;
    let num = n;

    while (num > 0) {
        const digit = num % 10;

        sum += digit;
        product *= digit;

        num = Math.floor(num / 10);
    }

    const divisor = sum + product;

    return n % divisor === 0;
}
```

## 🧪 Dry Run

Consider:

```txt
n = 23
```

Initial:

```txt
sum = 0
product = 1
```

### Extract `3`

```txt
sum = 0 + 3 = 3
product = 1 × 3 = 3
num = 2
```

### Extract `2`

```txt
sum = 3 + 2 = 5
product = 3 × 2 = 6
num = 0
```

Now:

```txt
digit sum     = 5
digit product = 6
```

Therefore:

```txt
divisor = 5 + 6 = 11
```

Check:

```txt
23 % 11 !== 0
```

So:

```txt
false
```

---

## Why It Works

Every iteration processes exactly one digit.

For each digit `d`:

```txt
sum     += d
product *= d
```

After all digits have been processed:

```txt
sum
```

contains the complete digit sum, and:

```txt
product
```

contains the complete digit product.

Therefore:

```txt
sum + product
```

is exactly the divisor specified by the problem.

The final modulo operation then directly answers whether `n` is divisible by that divisor.

---

## ⏱️ Complexity

Let `d` be the number of digits in `n`.

Each digit is processed exactly once:

```txt
Time: O(d)
```

Only a constant number of variables are used:

```txt
Space: O(1)
```

Given:

```txt
n <= 10^6
```

the number of digits is very small, so this is effectively:

```txt
Time: O(1)
Space: O(1)
```

under the given constraints.

---

## 🏆 Final Recommendation

The direct digit-extraction solution is the correct and preferred approach.

There is no need for:

- Strings
- Arrays
- Hash Maps
- Sorting
- Recursion
- Dynamic Programming

The important reusable pattern is:

```txt
Number
  ↓
Extract digits using % 10
  ↓
Remove digit using / 10
  ↓
Accumulate required values
  ↓
Perform final calculation
```

### Key Takeaways

- `% 10` gives the last digit.
- `Math.floor(num / 10)` removes the last digit.
- Use `sum = 0` for addition.
- Use `product = 1` for multiplication.
- The complexity of digit-processing problems is usually `O(d)`, where `d` is the number of digits.
- When `d` is bounded by a small constant, `O(d)` is effectively `O(1)`.
