# 🧩 Problem #2409 – Count Days Spent Together

**Difficulty:** Easy  
**Topics:** `Math`, `Intervals`      
**Link:** https://leetcode.com/problems/count-days-spent-together/

---

## 📝 Problem Summary

Given Alice's arrival and departure dates and Bob's arrival and departure dates, calculate how many days they spend together in the same city.

- Dates use the `"MM-DD"` format.
- All dates belong to the same non-leap year.
- Arrival and departure dates are **inclusive**.

## 💡 Core Insight

Treat each person's stay as an interval:

- Alice: `[aliceStart, aliceEnd]`
- Bob: `[bobStart, bobEnd]`

The overlapping interval starts at the **later arrival date** and ends at the **earlier departure date**.

\[
\text{start}=\max(\text{aliceStart},\text{bobStart})
\]

\[
\text{end}=\min(\text{aliceEnd},\text{bobEnd})
\]

If `start > end`, there is no overlap, so return `0`.

Otherwise, the number of days together is:

\[
\boxed{\text{end}-\text{start}+1}
\]

The `+1` is essential because both endpoints are included.

## 🎯 Pattern Recognition

This is an **interval intersection** problem.

Whenever a problem asks for the common duration between two ranges, think about:

1. Finding the later starting point.
2. Finding the earlier ending point.
3. Checking whether the resulting interval is valid.
4. Counting the inclusive range.

The same pattern applies to meeting schedules, booking periods, and overlapping date ranges.

## 🚀 Evolution of Thought Process

1. **Understand the date format:** `"MM-DD"` contains a month and a day, but dates from different months cannot be subtracted directly.
2. **Normalize the dates:** Convert each date into its day number within the year.
3. **Find the overlap:** Take the maximum arrival day and minimum departure day.
4. **Handle non-overlapping stays:** If the later arrival is after the earlier departure, return `0`.
5. **Count inclusive days:** Subtract the start from the end and add `1`.

An alternative observation is that zero-padded `"MM-DD"` strings can be compared lexicographically because all dates belong to the same year and use the same fixed-width format.

## 🔍 Detailed Reasoning

### Approach 1 — Day-of-Year Conversion (My Solution)

The `cumulativeDays` array stores the number of days elapsed through the end of each month.

```typescript
const cumulativeDays = [
    31, 59, 90, 120, 151, 181,
    212, 243, 273, 304, 334, 365
];
```

For a date such as `"08-15"`:

- Days before August: `cumulativeDays[6] = 212`
- Day within August: `15`
- Day of year: `212 + 15 = 227`

January is handled separately because there are no days before January.

### 🧩 Approach 1 — My Solution

```typescript
function countDaysTogether(
    arriveAlice: string,
    leaveAlice: string,
    arriveBob: string,
    leaveBob: string
): number {
    const cumulativeDays = [
        31, 59, 90, 120, 151, 181,
        212, 243, 273, 304, 334, 365
    ];

    function getDayOfYear(date: string): number {
        const [monthString, dayString] = date.split("-");
        const month = Number(monthString);
        const day = Number(dayString);

        const daysBeforeMonth =
            month === 1 ? 0 : cumulativeDays[month - 2];

        return daysBeforeMonth + day;
    }

    const aliceStart = getDayOfYear(arriveAlice);
    const aliceEnd = getDayOfYear(leaveAlice);

    const bobStart = getDayOfYear(arriveBob);
    const bobEnd = getDayOfYear(leaveBob);

    // No overlap if either person leaves before the other arrives.
    if (aliceEnd < bobStart || bobEnd < aliceStart) {
        return 0;
    }

    const start = Math.max(aliceStart, bobStart);
    const end = Math.min(aliceEnd, bobEnd);

    return end - start + 1;
}
```

**Why this works:** Converting dates to day numbers preserves chronological order and makes subtraction meaningful. The interval intersection then gives the exact number of shared days.

### 🧩 Approach 2 — Direct String Comparison

Because dates are zero-padded and formatted as `"MM-DD"`, string comparison follows chronological order within the same year.

For example:

- `"08-16" < "08-18"` is `true`.
- `"10-01" < "11-01"` is `true`.

```typescript
function countDaysTogether(
    arriveAlice: string,
    leaveAlice: string,
    arriveBob: string,
    leaveBob: string
): number {
    const start =
        arriveAlice > arriveBob ? arriveAlice : arriveBob;

    const end =
        leaveAlice < leaveBob ? leaveAlice : leaveBob;

    if (start > end) {
        return 0;
    }

    const toDayOfYear = (date: string): number => {
        const [month, day] = date.split("-").map(Number);

        const cumulativeDays = [
            31, 59, 90, 120, 151, 181,
            212, 243, 273, 304, 334, 365
        ];

        return (month === 1 ? 0 : cumulativeDays[month - 2]) + day;
    };

    return toDayOfYear(end) - toDayOfYear(start) + 1;
}
```

This version uses strings to determine the overlapping interval, then converts only the two overlapping endpoints to day numbers to calculate the duration.

**Important:** Direct string comparison alone cannot calculate the number of days between two dates. For example, `"08-18" - "08-16"` produces `NaN`, not `2`.

## 🧪 Dry Run

**Input:**

```text
arriveAlice = "08-15"
leaveAlice  = "08-18"
arriveBob   = "08-16"
leaveBob    = "08-19"
```

Convert the dates:

| Date | Day of year |
|---|---:|
| Alice arrives: `08-15` | 227 |
| Alice leaves: `08-18` | 230 |
| Bob arrives: `08-16` | 228 |
| Bob leaves: `08-19` | 231 |

Find the overlapping interval:

- Start = `max(227, 228) = 228`
- End = `min(230, 231) = 230`

Calculate:

\[
230-228+1=\boxed{3}
\]

**Output:** `3`

The shared dates are August 16, 17, and 18.

## ⚖️ Correctness

The later arrival date is the earliest day on which both people can be present. The earlier departure date is the latest day on which both can be present.

If the calculated start exceeds the end, no shared day exists. Otherwise, every day in that interval belongs to both stays.

Since the endpoints are inclusive, the interval contains `end - start + 1` days. Therefore, the algorithm returns the correct answer.

## ⏱️ Complexity Analysis

Let \(n\) represent the input date-string length.

**Approach 1 — Day-of-Year Conversion**

- **Time:** \(O(1)\). Each date has a fixed format and bounded length, and the month lookup is constant time.
- **Space:** \(O(1)\). The cumulative-days array has a fixed size of 12, and the input strings have fixed length.

**Approach 2 — Direct String Comparison**

- **Time:** \(O(1)\). The four date strings have fixed length, and only two endpoints need conversion.
- **Space:** \(O(1)\). The temporary arrays and date components have fixed, bounded sizes.

Both approaches are optimal in asymptotic complexity.

## 🏆 Key Takeaways

1. Recognize interval intersection problems instead of checking every day individually.
2. The overlap begins at the later start and ends at the earlier finish.
3. Inclusive intervals require `+1` when counting days.
4. Fixed-width, zero-padded `"MM-DD"` strings can be compared chronologically within the same year.
5. String comparison determines order, but date conversion is still needed to calculate a duration.
6. Clear variable names such as `cumulativeDays`, `aliceStart`, and `bobEnd` make date logic easier to understand.

## 📚 Pattern Learned

**Interval Intersection**

For two inclusive intervals `[aStart, aEnd]` and `[bStart, bEnd]`:

\[
\text{start}=\max(aStart,bStart)
\]

\[
\text{end}=\min(aEnd,bEnd)
\]

\[
\text{answer}=
\begin{cases}
0 & \text{if start}>\text{end}\\
\text{end}-\text{start}+1 & \text{otherwise}
\end{cases}
\]

Practice this pattern in scheduling, date ranges, booking systems, and overlapping availability problems.
