# 🧩 Problem #3870 – Count Commas in Range

**Difficulty:** Easy  
**Topics:** `Math`     
**Link:** https://leetcode.com/problems/count-commas-in-range/

---

## 📝 Problem Summary

Given an integer `n`, count the total number of commas used when writing every integer from `1` to `n` using standard number formatting.

A comma is inserted after every three digits from the right.

Because `n <= 10^5`, every number in the range can contain at most one comma.

---

## 💡 Core Insight

Numbers from `1` through `999` contain no commas.

Starting from `1000`, every number contains exactly one comma.

So instead of checking every number, we only need to count how many numbers are in the range `[1000, n]`.

The number of integers in an inclusive range `[a, b]` is:

    b - a + 1

Therefore:

    n - 1000 + 1
    = n - 999

If `n < 1000`, the answer is `0`.

---

## 🎯 Pattern Recognition

The important clue is the constraint:

    1 <= n <= 10^5

Since `n` is at most `100000`, no number can contain more than one comma.

This means we don't need to simulate number formatting.

Instead, identify the threshold where commas first appear:

    1000

Then count all numbers from that threshold through `n`.

This is a **threshold + range counting** pattern.

---

## 🚀 Evolution of Thought Process

### Brute Force

A natural first approach would be:

1. Iterate through every number from `1` to `n`.
2. Convert each number to standard formatting.
3. Count its commas.
4. Add them together.

For example:

    1000 → "1,000" → 1 comma
    1001 → "1,001" → 1 comma
    1002 → "1,002" → 1 comma

But this is unnecessary.

### Observation

Numbers below `1000` contribute nothing:

    1 ... 999 → 0 commas

Every number from `1000` onward contributes exactly one comma because `n <= 10^5`:

    1000 ... 100000 → 1 comma each

Therefore, the problem reduces to counting the numbers in:

    [1000, n]

### Final Approach

    if n < 1000:
        return 0

    return n - 999

---

## 🔍 Detailed Reasoning

The first number containing a comma is `1000`.

For `n >= 1000`, the numbers contributing one comma are:

    1000, 1001, 1002, ..., n

The number of values in this inclusive range is:

    n - 1000 + 1

The `+1` is necessary because both `1000` and `n` are included.

Simplifying:

    n - 1000 + 1
    = n - 999

### Example 1

    n = 1002

Numbers containing commas:

    1000 → 1 comma
    1001 → 1 comma
    1002 → 1 comma

Total:

    3

Using the formula:

    1002 - 999 = 3

### Example 2

    n = 998

Every number has fewer than four digits, so none contains a comma.

Answer:

    0

---

## 🧩 Approach 1 — My Solution

My solution directly applies the threshold observation.

    function countCommas(n: number): number {
        if (n < 1000) return 0;

        return n - 999;
    }

### Why it works

- If `n < 1000`, there are no commas.
- If `n >= 1000`, every number from `1000` to `n` has exactly one comma.
- The number of such numbers is `n - 999`.

There is no need for iteration, string conversion, or number formatting.

---

## ⚖️ Correctness

We divide the numbers into two ranges.

### Range 1: `1 ... 999`

All numbers have fewer than four digits.

Therefore:

    commas = 0

### Range 2: `1000 ... n`

Because `n <= 10^5`, every number in this range has exactly one comma.

Therefore:

    total commas
    = number of integers from 1000 to n
    = n - 1000 + 1
    = n - 999

Thus the algorithm returns the correct total.

**Time:** `O(1)`

The solution performs only a constant number of operations.

**Space:** `O(1)`

No additional data structures are used.

## 🏆 Key Takeaways

- Check the constraints before deciding to simulate.
- Identify the first value where the required property appears.
- Here, commas first appear at `1000`.
- Because `n <= 10^5`, every relevant number contributes exactly one comma.
- Count the valid range instead of processing every number.
- For an inclusive range `[a, b]`, the number of elements is `b - a + 1`.
- A problem that looks like string formatting can sometimes be reduced to simple arithmetic.

---

## 📚 Pattern Learned

### Threshold + Range Counting

When a property starts being true from a particular threshold, ask:

> Can I count all values satisfying the property directly instead of checking each value?

For this problem:

    threshold = 1000

    count = n - 1000 + 1
          = n - 999

The reusable lesson is:

**Recognize the threshold → count the valid range → avoid unnecessary simulation.**
