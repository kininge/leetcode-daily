# 🧩 Problem #3903 – Smallest Stable Index I

**Difficulty:** Easy  
**Topics:** `Prefix`, `Array`  
**Link:** https://leetcode.com/problems/smallest-stable-index-i/

---

## 📝 Problem Summary

For every index `i`, define its instability score as:

    max(nums[0..i]) - min(nums[i..n-1])

An index `i` is **stable** if its instability score is less than or equal to `k`.

Return the **smallest stable index**.

If no stable index exists, return `-1`.

---

## 💡 Intuition

For every index `i`, we need two values:

    max(nums[0..i])
    min(nums[i..n-1])

The first value is a **prefix maximum**.

The second value is a **suffix minimum**.

Instead of calculating these values repeatedly for every index, we can:

1. Precompute the suffix minimum for every index.
2. Scan from left to right while maintaining the prefix maximum.
3. Calculate the instability score.
4. Return the first index whose score is `<= k`.

Because we scan from left to right, the first stable index is automatically the smallest stable index.

---

## 🎯 Pattern Recognition

The problem directly asks for information from both sides of every index:

| Requirement | Technique |
|---|---|
| `max(nums[0..i])` | Prefix Maximum |
| `min(nums[i..n-1])` | Suffix Minimum |
| Smallest valid index | Left-to-right scan |

The important observation is that we don't need to recalculate the ranges for every index.

---

## 🚀 Evolution of Thought Process

A straightforward approach would be:

    For every index i:
        calculate max(nums[0..i])
        calculate min(nums[i..n-1])

This repeats work.

Instead, preprocess the suffix minimum:

    suffixMin[i] = minimum value from i to n-1

Then maintain the prefix maximum during the left-to-right scan:

    prefixMax = maximum value from 0 to i

Now the instability score can be calculated in O(1):

    instability = prefixMax - suffixMin[i]

So the overall process becomes:

    Build suffix minimum
            ↓
    Scan from left to right
            ↓
    Maintain prefix maximum
            ↓
    Calculate instability
            ↓
    Return first score <= k

---

## 🔍 Detailed Reasoning

### Step 1 — Build Suffix Minimum

Define:

    suffixMin[i] = minimum value from index i to n-1

For example:

    nums = [5, 0, 1, 4]

The suffix minimum array is:

    index:      0  1  2  3
    nums:       5  0  1  4
    suffixMin:  0  0  1  4

We build it from right to left.

The recurrence is:

    suffixMin[n - 1] = nums[n - 1]

    suffixMin[i] = min(nums[i], suffixMin[i + 1])

---

### Step 2 — Maintain Prefix Maximum

Now scan the array from left to right.

Maintain:

    prefixMax = maximum value seen so far

At every index:

    prefixMax = max(prefixMax, nums[i])

Therefore, at index `i`:

    prefixMax = max(nums[0..i])

---

### Step 3 — Calculate Instability

Now we have exactly the two values required by the problem:

    prefixMax
    suffixMin[i]

Therefore:

    instability = prefixMax - suffixMin[i]

If:

    instability <= k

then index `i` is stable.

---

### Step 4 — Return the First Stable Index

The problem asks for the **smallest index**, not the smallest instability score.

Since we scan:

    0 → 1 → 2 → ... → n-1

the first index satisfying:

    instability <= k

is automatically the smallest stable index.

This was the important bug in the initial solution.

The initial implementation compared:

    diff < smallestStableIndex

But `smallestStableIndex` was actually storing the smallest **score**, not the smallest **index**.

The correct logic is simply:

    if (diff <= k) return i;

---

## 🧪 Dry Run

Consider:

    nums = [5, 0, 1, 4]
    k = 3

### Suffix Minimum

    nums:       5   0   1   4
    suffixMin:  0   0   1   4

### Scan

At `i = 0`:

    prefixMax = 5
    suffixMin[0] = 0

    instability = 5 - 0 = 5

    5 > 3
    Not stable.


At `i = 1`:

    prefixMax = 5
    suffixMin[1] = 0

    instability = 5 - 0 = 5

    5 > 3
    Not stable.


At `i = 2`:

    prefixMax = 5
    suffixMin[2] = 1

    instability = 5 - 1 = 4

    4 > 3
    Not stable.


At `i = 3`:

    prefixMax = 5
    suffixMin[3] = 4

    instability = 5 - 4 = 1

    1 <= 3
    Stable.

Therefore:

    answer = 3

## 🧩 Solution — Prefix Maximum + Suffix Minimum

### Code (TypeScript)

```ts
function firstStableIndex(nums: number[], k: number): number {
    const n = nums.length;

    const suffixMin = new Array(n);
    suffixMin[n - 1] = nums[n - 1];

    // Build suffix minimum.
    for (let i = n - 2; i >= 0; i--) {
        suffixMin[i] = Math.min(suffixMin[i + 1], nums[i]);
    }

    let prefixMax = 0;

    // Scan from left to right.
    for (let i = 0; i < n; i++) {
        prefixMax = Math.max(prefixMax, nums[i]);

        const instability = prefixMax - suffixMin[i];

        if (instability <= k) {
            return i;
        }
    }

    return -1;
}
```

## ⏱️ Complexity Analysis

### Time Complexity

Building the suffix minimum requires one traversal: `O(n)`

The second traversal maintains the prefix maximum and checks every index: `O(n)`

Therefore:

Time: `O(n)`


### Space Complexity

The suffix minimum array contains n elements:

Space: `O(n)`

## 🏆 Key Takeaways

1. When a problem asks for: 
```txt
max(nums[0..i])
```
think prefix maximum.

2. When it asks for: 
```txt
min(nums[i..n-1])
```
think suffix minimum.

3. If both sides are required for every index, consider combining:
```txt
Prefix preprocessing
+
Suffix preprocessing
```
4. If the problem asks for the smallest valid index, scanning from left to right allows an immediate return.

5. Be careful about what the problem is asking to minimize:
```txt
❌ smallest instability score

✅ smallest index whose instability score <= k
```

## 📚 Pattern Learned

### Prefix + Suffix Preprocessing

A common pattern is:
```txt
Information from the left
            +
Information from the right
            ↓
    Decision at index i
```

Typical examples involve:

- Prefix maximum
- Prefix minimum
- Prefix sum
- Suffix maximum
- Suffix minimum
Left/right boundaries

A useful question to ask when seeing these problems:
```txt
"Can I precompute the information from one direction and maintain the other direction while scanning?"
```
