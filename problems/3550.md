# 🧩 Problem #3550 – Smallest Index With Digit Sum Equal to Index

**Difficulty:** Easy  
**Topics:** `Array`, `Math`    
**Link:** https://leetcode.com/problems/smallest-index-with-digit-sum-equal-to-index/

---

## 📝 Problem Summary

Given an integer array `nums`, find the **smallest index** `i` such that the sum of the digits of `nums[i]` is equal to `i`.

If no such index exists, return `-1`.

---

## 💡 Core Insight

The array needs to be checked from left to right.

For every index:

1. Calculate the digit sum of `nums[i]`.
2. Compare it with `i`.
3. If they are equal, immediately return `i`.

Because we scan indices in increasing order, the **first matching index is automatically the smallest index**.

No sorting, extra data structure, or optimization is necessary.

---

## 🎯 Pattern Recognition

This is a straightforward **array traversal + digit manipulation** problem.

The important observation is:

> When the problem asks for the **smallest index** satisfying a condition, scanning from index `0` toward the end allows us to return immediately when the first match is found.

The digit sum itself can be calculated by repeatedly extracting the last digit:

    num % 10

and removing that digit:

    Math.floor(num / 10)

---

## 🚀 Evolution of Thought Process

The problem directly suggests a linear scan.

For each element:

    nums[i]

calculate:

    digitSum(nums[i])

Then check:

    digitSum(nums[i]) === i

Since we are scanning from left to right, once the condition is satisfied, we don't need to inspect any later elements.

This gives a simple and efficient solution.

---

## 🔍 Detailed Reasoning

Suppose:

    nums = [1, 10, 11]

Start from index `0`.

### Index 0

    nums[0] = 1
    digit sum = 1

Compare:

    1 === 0

False.

### Index 1

    nums[1] = 10
    digit sum = 1 + 0 = 1

Compare:

    1 === 1

True.

Therefore:

    answer = 1

We can immediately return because every later index is greater than `1`.

## 🧪 Dry Run

For:

    nums = [1, 3, 2]

| Index | Value | Digit Sum | Match? |
| ----- | ----- | --------- | ------ |
| 0 | 1 | 1 | No |
| 1 | 3 | 3 | No |
| 2 | 2 | 2 | Yes |

At index `2`:

    digitSum(2) === 2

So the answer is:

    2

## 🧩 Approach 1 — My Solution

### Idea

Create a helper function to calculate the digit sum.

Then iterate through the array from left to right.

If the digit sum equals the current index, return the index immediately.

### TypeScript

```ts
function smallestIndex(nums: number[]): number {
    function digitSum(num: number): number {
        let sum = 0;

        while (num > 0) {
            const remainder = num % 10;
            num = Math.floor(num / 10);
            sum += remainder;
        }

        return sum;
    }

    for (let i = 0; i < nums.length; i++) {
        const sum = digitSum(nums[i]);

        if (i === sum) {
            return i;
        }
    }

    return -1;
}
```

### Note

The original solution had:

    if (num < 10) return num;

This is correct, but unnecessary.

The `while` loop already handles single-digit numbers correctly:

    num = 7
    sum = 0

    7 % 10 = 7
    num becomes 0

    sum = 7

So the extra condition can be removed.

Also, `reminder` was renamed to `remainder` because `remainder` is the correct mathematical term.

---

## ⚖️ Correctness

We iterate through every index in increasing order:

    0 → 1 → 2 → ... → n - 1

For each index `i`, we calculate the exact digit sum of `nums[i]`.

If:

    digitSum(nums[i]) === i

then `i` satisfies the required condition.

Because all smaller indices have already been checked, and none satisfied the condition, this `i` must be the smallest valid index.

If the loop finishes without finding a match, no valid index exists, so we return `-1`.

---

## ⏱️ Complexity Analysis

Let `d` be the maximum number of digits in any number.

**Time:** `O(n × d)`

For every one of the `n` elements, we process at most `d` digits.

Given the constraint:

    nums[i] <= 1000

there are at most 4 digits, so `d` is bounded by a constant.

Therefore, for these constraints, this is effectively:

    O(n)

**Space:** `O(1)`

Only a few variables are used.

## 🏆 Key Takeaways

1. Scan from left to right when looking for the **smallest index**.
2. Return immediately when the first valid index is found.
3. Digit sum can be calculated using:
   
       num % 10
   
   to extract the last digit and:
   
       Math.floor(num / 10)
   
   to remove it.
4. Don't add special cases when the general loop already handles them.
5. Always distinguish practical complexity from the formal complexity:
   
       O(n × d)
   
   becomes effectively `O(n)` when `d` is bounded by a small constant.

## 📚 Pattern Learned

### Linear Scan + Digit Manipulation

When a problem asks you to find an index satisfying a property of each number:

    for each index
        ↓
    calculate property
        ↓
    compare with index
        ↓
    return first match

For digit-related properties, common techniques include:

    num % 10

and:

    Math.floor(num / 10)

This is a simple but reusable pattern for number-processing problems.
