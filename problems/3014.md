# 🧩 Problem #3014 - Minimum Number of Pushes to Type Word I

**Difficulty:** Easy        
**Topics:** `Greedy`, `Math`       
**Link:** https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-i/

## 💡 Intuition

Although the problem talks about **telephone keypads**, the keypad layout itself is actually irrelevant.

The only thing that matters is the **cost of each available position**.

There are **8 keys** (`2` to `9`).

Each key provides:

* one position costing **1 push**,
* one position costing **2 pushes**,
* one position costing **3 pushes**, and so on.

Think of the keypad as generating **cost slots**.

```text
Push Cost = 1

Key2 Key3 Key4 Key5 Key6 Key7 Key8 Key9

  1    1    1    1    1    1    1    1
```

There are **8 cheapest slots**.

After filling those, the next available slots cost **2 pushes**.

```text
Push Cost = 2

Key2 Key3 Key4 Key5 Key6 Key7 Key8 Key9

  2    2    2    2    2    2    2    2
```

Again, there are **8 slots**.

Since every character appears **exactly once**, every character has equal importance.

Therefore, the greedy strategy is simple:

> Fill the cheapest available positions first.

# 🧠 Attempt 1 — Greedy Counting (Accepted)

## Idea

Count

* how many complete groups of 8 characters exist,
* how many characters remain.

Each complete group contributes

```text
8 × pushCost
```

The remaining characters all belong to the next push level.

---

## Your Solution

```ts
function minimumPushes(word: string): number {
    const n = word.length;

    const batch = Math.floor(n / 8);
    const extra = n % 8;

    let cost = 0;

    for (let i = 1; i <= batch; i++)
        cost += 8 * i;

    cost += extra * (batch + 1);

    return cost;
}
```

# 🧠 Attempt 2 — Mathematical Formula

Your solution already computes

```text
8×1
+
8×2
+
...
+
8×batch
```

This is simply an arithmetic progression.

Recall the formula

```text
1 + 2 + ... + k

=

k(k+1)/2
```

Therefore,

```text
8×1
+
8×2
+
...
+
8×batch
```

becomes

```text
8 × (1+2+...+batch)
```

Substitute the arithmetic series formula.

```text
8 × batch(batch+1)/2
```

Simplify.

```text
4 × batch(batch+1)
```

Now add the remaining characters.

```text
extra × (batch+1)
```

Final formula

```text
Answer

=

4 × batch × (batch+1)

+

extra × (batch+1)
```

Implementation

```ts
function minimumPushes(word: string): number {
    const batch = Math.floor(word.length / 8);
    const extra = word.length % 8;

    return 4 * batch * (batch + 1)
         + extra * (batch + 1);
}
```

This removes the loop entirely while producing the same result.

# ✅ Why Greedy Works

Every character appears exactly once.

No character is more important than another.

Therefore, assigning any character to a cheaper slot can never make the answer worse.

Since each push level provides exactly eight positions, the optimal strategy is simply:

1. Fill every cost-1 slot.
2. Fill every cost-2 slot.
3. Continue until all characters are assigned.

No other arrangement can produce a smaller total cost.
