# 🧩 Problem #3345 - Smallest Divisible Digit Product I

**Difficulty:** Easy  
**Topics:** `Simulation`, `Math`   
**Link:** https://leetcode.com/problems/smallest-divisible-digit-product-i/description.   

---

## 💡 Intuition

We need to find the **smallest** number greater than or equal to `n` whose digit product is divisible by `t`.

The constraints are very small:

```text
1 <= n <= 100
1 <= t <= 10
```

This immediately suggests a brute-force search.

For each candidate number:

1. Compute the product of its digits.
2. Check whether the product is divisible by `t`.
3. Return the first valid number.

## ✅ Solution

```ts
function smallestNumber(n: number, t: number): number {
    function digitProduct(num: number): number {
        let product = 1;

        while (num > 0) {
            product *= num % 10;
            num = Math.floor(num / 10);
        }

        return product;
    }

    let num = n;

    while (true) {
        if (digitProduct(num) % t === 0) {
            return num;
        }

        num++;
    }
}
```

---

## ⚖️ Why It Works

We examine numbers in increasing order starting from `n`.

The first number satisfying

```text
digitProduct(number) % t == 0
```

is guaranteed to be the smallest valid answer.

---

## ⏱ Complexity Analysis

Let

```text
d = number of digits
```

Each digit-product computation takes

```text
O(d)
```

Since

```text
n <= 100
```

```text
d <= 3
```

Therefore each iteration is

```text
O(1)
```

Overall

```text
O(k)
```

where `k` is the number of candidate numbers tested.

Space

```text
O(1)
```
