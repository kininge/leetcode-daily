# 🧩 Problem #3963 – Create Grid With Exactly One Path

**Difficulty:** Easy  
**Topics:** `Matrix`, `String`     
**Link:** https://leetcode.com/problems/create-grid-with-exactly-one-path/

---

## 📝 Problem Summary

Given two integers `m` and `n`, construct an `m × n` grid containing only `'.'` and `'#'`.

- `'.'` represents a free cell.
- `'#'` represents an obstacle.

A valid path starts at `(0, 0)`, ends at `(m - 1, n - 1)`, and moves only right or down.

Return any grid that contains **exactly one valid path** between these two cells.

---

## 💡 Core Insight

We don't need to search for a path or count possible paths. We can directly construct a grid that guarantees exactly one path.

**Create an L-shaped path:**
1. Make the first column entirely free.
2. Make the last row entirely free.
3. Block every other cell.

This forces the path to move down the first column and then right along the last row.

---

## 🎯 Pattern Recognition

This is a **Constructive Algorithm** problem.

Look for this pattern when a problem asks you to:
- Construct any valid arrangement.
- Return a configuration satisfying specific conditions.
- Design a structure that guarantees a particular property.

Unlike typical algorithmic problems, we don't need to calculate the answer from an existing input structure. We design the answer ourselves.

---

## 🚀 Evolution of Thought Process

### Step 1 — Understand the requirement

We need exactly one path from the top-left to the bottom-right cell.

If every cell is free, multiple paths are possible because we can interleave right and down movements in different orders.

### Step 2 — Eliminate alternative paths

Block cells to prevent the path from branching into multiple possible routes.

### Step 3 — Construct an L-shaped path

Keep the first column and the last row free. Block all remaining cells.

For `m = 3, n = 4`:

```txt
.###
.###
....
```

The only valid path is:

```txt
(0,0) → (1,0) → (2,0) → (2,1) → (2,2) → (2,3)
```

### Step 4 — Handle edge cases

- If `m = 1`, the only row is entirely free.
- If `n = 1`, the only column is entirely free.
- If `m = n = 1`, the grid contains a single free cell.

The same construction handles all these cases without special conditions.

---

## 🔍 Detailed Reasoning

For every cell `(i, j)`, use the following rule:

- If `i === m - 1`, make the cell `'.'`.
- Otherwise, make the cell `'.'` only if `j === 0`; use `'#'` for all other columns.

This creates a free first column and a free last row.

### Why is the path unique?

For every row except the last, only the first-column cell is free. Therefore, the path cannot move right before reaching the last row.

Once the path reaches the last row, every cell in that row is free, so it can move right until it reaches the destination.

Thus, the only possible path is to move down the first column and then right along the last row.

## 🧩 Approach 1 — L-Shaped Path Construction

### TypeScript Code

```ts
function createGrid(m: number, n: number): string[] {
    const ans: string[] = [];

    for (let i = 0; i < m; i++) {
        let row = '';

        if (i === m - 1) {
            row = '.'.repeat(n);
        } else {
            row = '.' + '#'.repeat(n - 1);
        }

        ans.push(row);
    }

    return ans;
}
```

### Code Explanation

**1. Iterate through every row**

```txt
for (let i = 0; i < m; i++)
```

Construct each row independently.

**2. Make the last row entirely free**

```txt
if (i === m - 1) {
    row = '.'.repeat(n);
}
```

This provides the horizontal portion of the L-shaped path.

**3. Block all cells except the first column in other rows**

```txt
else {
    row = '.' + '#'.repeat(n - 1);
}
```

The first cell remains free, allowing downward movement. Every other cell becomes an obstacle.

**4. Store the row**

```txt
ans.push(row);
```

After constructing all rows, return the grid.


| Row index `i` | Condition | Constructed row |

| 0 | `i !== m - 1` | `.###` |
| 1 | `i !== m - 1` | `.###` |
| 2 | `i === m - 1` | `....` |

**Output:**

```txt
[
    ".###",
    ".###",
    "...."
]
```

The unique path is:

```txt
.###
.###
....
```

Move down twice along the first column, then right three times along the last row.

The path contains `m + n - 2 = 5` moves.

## ⚖️ Correctness

The construction guarantees exactly one valid path.

**Existence:** Every cell in the first column and the last row is free. Therefore, we can reach the destination by moving down the first column and then right along the last row.

**Uniqueness:** Before reaching the last row, every cell to the right of the first column is blocked. Consequently, the path must continue down the first column. After reaching the last row, it can move right to the destination.

Therefore, exactly one valid path exists.

---

## ⏱️ Complexity Analysis

Let `m` be the number of rows and `n` be the number of columns.

**Time:** `O(m × n)`

We construct `m` rows containing `n` characters each. The total construction work is proportional to the number of cells.

**Auxiliary Space:** `O(n)` for the temporary row, excluding the returned grid.

**Output Space:** `O(m × n)` for the complete grid.

## 🏆 Key Takeaways

1. **Constructive algorithms:** Sometimes the best solution is to design a valid output directly rather than calculate an answer.
2. **Control the possibilities:** Obstacles eliminate unwanted paths.
3. **Prove uniqueness:** Showing that a path exists is not enough; we must also demonstrate that no alternative path exists.
4. **Reuse one construction:** A well-designed construction often handles edge cases without additional conditions.
5. **Optimal construction:** Since the output contains `m × n` cells, `O(m × n)` time is optimal.
