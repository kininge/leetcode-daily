# 🧩 Problem #3517 - Smallest Palindromic Rearrangement I

**Difficulty:** Medium    
**Topics:** `String`, `Greedy`, `Hash Map`    
**Link:** https://leetcode.com/problems/smallest-palindromic-rearrangement-i/   

---

## 💡 Intuition

A palindrome is completely determined by its **first half**.

Once the first half is fixed:

* the middle character (if any) is determined by the odd-frequency character,
* the second half is simply the mirror image of the first half.

Therefore, to obtain the **lexicographically smallest palindrome**, we only need to make the **first half** as small as possible.

Since the string contains only lowercase English letters, counting frequencies is more efficient than sorting.

## 🔍 Key Observation

For every character:

* Half of its occurrences belong to the left side.
* Half belong to the right side.
* If the frequency is odd, exactly one occurrence must stay in the middle.

Example

```text
a : 4
b : 2
c : 3
```

becomes

```text
Left   : aabc
Middle : c
Right  : cbaa
```

Final palindrome

```text
aabccbaa
```

---

## 🧠 Why Greedy Works

Lexicographic order is decided from left to right.

Therefore, we should place the **smallest available characters** as early as possible.

Since the right half is forced to be the mirror of the left half, choosing the smallest possible left half automatically produces the smallest possible palindrome.

---

## 🧠 Attempt 1 — Frequency Counting + Greedy Construction (Accepted)

### Idea

1. Count the frequency of every letter.
2. Iterate from `'a'` to `'z'`.
3. If a character has an odd count:

   * Reserve one copy for the middle.
   * Split the remaining copies equally.
4. Append half to the first half.
5. Prepend the same characters to the second half.

Because we process letters in alphabetical order, the first half is lexicographically smallest.

### Your Solution

```ts
function smallestPalindrome(s: string): string {
    // edge case
    if (s.length === 1) return s;

    const letters = new Array(26).fill(0);

    // Count frequencies
    for (const char of s) {
        const index = char.charCodeAt(0) - 97;
        letters[index]++;
    }

    let firstHalf = "";
    let secondHalf = "";
    let oddNumberedChar = "";

    for (let i = 0; i < 26; i++) {
        let count = letters[i];

        if (count === 0) continue;

        const char = String.fromCharCode(i + 97);

        if (count % 2 !== 0) {
            oddNumberedChar = char;
            count--;

            if (count === 0) continue;
        }

        const halfCount = count / 2;
        const charsToAdd = char.repeat(halfCount);

        firstHalf += charsToAdd;
        secondHalf = charsToAdd + secondHalf;
    }

    return firstHalf + oddNumberedChar + secondHalf;
}
```

## ✅ Why it Works

For every character:

* all copies except at most one must be paired,
* one half goes to the left,
* the other half must appear symmetrically on the right.

Processing characters from `'a'` to `'z'` guarantees that smaller letters occupy earlier positions in the left half.

Since the right half is uniquely determined by symmetry, no other arrangement can produce a lexicographically smaller palindrome.

## ⚖️ Complexity

Let `n` be the length of the string.

### Time

* Count frequencies: `O(n)`
* Iterate through the alphabet: `O(26)`
* Construct the palindrome: `O(n)`

Overall

```text
O(n)
```

### Space

**Auxiliary Space (excluding the output):**

* Frequency array: `O(26)` = `O(1)`

If the constructed output strings (`firstHalf`, `secondHalf`, and the final result) are included, the implementation uses `O(n)` space, which is why some references report `O(n)`.

## 🏆 Key Takeaways

* A palindrome is determined by its left half.
* The right half is always the mirror of the left half.
* Frequency counting is often preferable to sorting when the alphabet size is fixed.
* To obtain the lexicographically smallest palindrome, greedily build the left half from the smallest characters.
* Think about the structure of the required output before writing code.
