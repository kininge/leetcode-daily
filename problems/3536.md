# 🧩 Problem #3536 - Maximum Product of Two Digits

**Difficulty:** Easy     
**Topics:** `Math`, `Greedy`     
**Link:** https://leetcode.com/problems/maximum-product-of-two-digits/     

---

## 💡 Intuition

The maximum product can only come from the **two largest digits** in the number.

A straightforward approach would be:

1. Extract all digits.
2. Sort them.
3. Multiply the two largest.

However, sorting is unnecessary.

Since we only need the two largest digits, we can maintain them while scanning the digits exactly once.

## 🔍 Key Observation

The answer is always

```text
largestDigit × secondLargestDigit
```

There is no need to know the ordering of every digit.

Only the two largest values matter.

---

## 🧠 Attempt 1 — Extract and Sort

### Idea

Extract every digit into an array.

Sort the digits.

Multiply the last two elements.

### Complexity

```text
Time  : O(d log d)

Space : O(d)
```

where `d` is the number of digits.

Although correct, sorting performs more work than necessary.

---

## 🧠 Attempt 2 — Single Pass Tracking (Accepted)

### Idea

Maintain two variables:

* `largestDigit`
* `secondLargestDigit`

While scanning every digit,

* If the current digit becomes the new largest, move the previous largest to `secondLargestDigit`.
* Otherwise, update `secondLargestDigit` if necessary.

This guarantees that after one traversal, the two variables contain the largest two digits.

### Your Solution

```ts
function maxProduct(n: number): number {
    let largestDigit = 0;
    let secondLargestDigit = 0;

    let num = n;

    while (num > 0) {
        const digit = num % 10;
        num = Math.floor(num / 10);

        if (digit > largestDigit) {
            secondLargestDigit = largestDigit;
            largestDigit = digit;
        } else if (digit > secondLargestDigit) {
            secondLargestDigit = digit;
        }
    }

    return largestDigit * secondLargestDigit;
}
```

## ✅ Solution

```ts
function maxProduct(n: number): number {
    let largestDigit = 0;
    let secondLargestDigit = 0;

    let num = n;

    while (num > 0) {
        const digit = num % 10;
        num = Math.floor(num / 10);

        if (digit > largestDigit) {
            secondLargestDigit = largestDigit;
            largestDigit = digit;
        } else if (digit > secondLargestDigit) {
            secondLargestDigit = digit;
        }
    }

    return largestDigit * secondLargestDigit;
}
```

---

## ⚖️ Why it Works

During traversal, the following invariant is always maintained:

```text
largestDigit ≥ secondLargestDigit
```

Whenever a larger digit is found,

```text
new digit

↓

largestDigit

↓

secondLargestDigit
```

The previous largest becomes the second largest.

Otherwise,

only `secondLargestDigit` is updated when the current digit is larger than it.

After scanning every digit exactly once, the two variables contain the largest two digits of the number.

Their product is therefore the maximum possible product.

## ⏱ Complexity

Let `d` be the number of digits.

### Single Pass Tracking

```text
Time  : O(d)

Space : O(1)
```

Since

```text
n ≤ 10⁹
```

there are at most 10 digits, making the solution effectively constant time.

---

## 🏆 Key Takeaways

* If only the largest few elements are required, sorting is often unnecessary.
* Maintain the required values during a single traversal.
* When a new maximum is found, remember to shift the old maximum into the second maximum.
* Always test with duplicate values to ensure the logic handles them correctly.
