# 🧩 Problem #3718 – Smallest Missing Multiple of K

**Difficulty:** Easy  
**Topics:** `Array`, `Hash Map`   
**Link:** https://leetcode.com/problems/smallest-missing-multiple-of-k/

---

## 📝 Problem Summary

You are given:

- An integer array `nums`
- An integer `k`

We need to find the **smallest positive multiple of `k`** that does not appear in `nums`.

The multiples of `k` are:

```txt
k, 2k, 3k, 4k, 5k, ...
```

We need to return the first one that is missing.

---

### Example

```txt
nums = [8, 2, 3, 4, 6]
k = 2
```

Multiples of `2`:

```txt
2, 4, 6, 8, 10, 12, ...
```

Checking from the smallest:

```txt
2  → exists
4  → exists
6  → exists
8  → exists
10 → missing
```

Therefore:

```txt
answer = 10
```

---

## 💡 Intuition

The problem asks for the **smallest** missing multiple.

That gives us an important clue:

> We can generate multiples in increasing order.

Start with:

```txt
k
```

Then repeatedly add `k`:

```txt
k → 2k → 3k → 4k → ...
```

Because we check them in increasing order, the **first missing multiple is automatically the smallest missing multiple**.

The only remaining question is:

> How can we quickly check whether a number exists in `nums`?

A `Set` is ideal for this.

---

## 🧠 Key Observation

Convert `nums` into a `Set`:

```ts
const existingNums = new Set(nums);
```

Then membership checking becomes:

```ts
existingNums.has(multiple)
```

So the algorithm becomes:

```txt
Build Set
   ↓
multiple = k
   ↓
Does multiple exist?
   ↓
Yes → multiple += k
   ↓
No  → return multiple
```

The important part is that we **never need to check numbers that are not multiples of `k`**.

For example, if:

```txt
k = 5
```

we only care about:

```txt
5, 10, 15, 20, 25, ...
```

---

# 🛠 Approach 1 — Generate Multiples + Hash Set

## Idea

1. Store all values from `nums` in a `Set`.
2. Start with the smallest positive multiple, `k`.
3. Check whether the current multiple exists.
4. If it exists, move to the next multiple by adding `k`.
5. If it doesn't exist, return it.

---

## Code (TypeScript)

```ts
function missingMultiple(nums: number[], k: number): number {
    const existingNums = new Set(nums);

    let multiple = k;

    while (existingNums.has(multiple)) {
        multiple += k;
    }

    return multiple;
}
```

## Why It Works

There are two important properties.

### 1. Multiples are generated in increasing order

Starting from `k` and repeatedly adding `k` produces:

```txt
k < 2k < 3k < 4k < ...
```

So every candidate is smaller than the candidates checked after it.

### 2. We return the first missing candidate

Suppose we return `4k`.

That means:

```txt
k     exists
2k    exists
3k    exists
4k    missing
```

Therefore there cannot be a smaller missing positive multiple of `k`.

So the first missing multiple is necessarily the answer.

---

## ⏱️ Complexity

Let:

- `n = nums.length`
- `m` = number of multiples checked before finding the answer

Building the `Set` takes:

```txt
O(n)
```

Each multiple lookup is average:

```txt
O(1)
```

Therefore:

```txt
Time: O(n + m)
Space: O(n)
```

Under the given constraints, `nums[i] <= 100`, so there are only finitely many relevant values in the input, and the answer is found quickly.

---

## 🏆 Final Recommendation

The `Set` + increasing-multiple enumeration solution is simple and appropriate.

There is no need for:

- Sorting
- Binary Search
- Dynamic Programming
- Complex mathematics
- Frequency Maps

The reusable pattern is:

```txt
Generate candidates in required order
              ↓
      Check existence quickly
              ↓
   Return first missing candidate
```

### Key Takeaways

- When a problem asks for the **smallest** missing value, consider generating candidates in increasing order.
- If candidates follow a simple sequence such as `k, 2k, 3k...`, enumerate them directly.
- Use a `Set` when the main operation is existence checking.
- Returning the first missing candidate works because candidates are examined in sorted order.
